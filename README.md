# 🇧🇷🇯🇵 Notícias Brasil & Japão

**Projeto open-source que reúne, organiza e acompanha tudo o que acontece de notícias no Brasil e no Japão.**

Atualizações diárias sobre política, economia, cultura, tecnologia, esportes, sociedade e muito mais.

---

## 📰 Objetivo

Centralizar as principais notícias dos dois países em um só lugar, de forma clara, organizada e atualizada.

- Notícias do **Brasil**
- Notícias do **Japão**
- Notícias relacionadas entre os dois países (diplomacia, comércio, cultura, intercâmbio etc.)

---

## 🚀 Como contribuir

1. Faça um fork do repositório
2. Crie uma branch (`git checkout -b feature/nova-noticia`)
3. Adicione a notícia no formato correto
4. Abra um Pull Request

### Formato sugerido para notícias:

```markdown
# Título da notícia

**Data:** AAAA-MM-DD  
**Fonte:** Nome da fonte  
**Link:** URL original  
**País:** Brasil / Japão / Bilateral

Resumo curto da notícia...

---
```
