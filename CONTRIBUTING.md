# Como contribuir

Obrigado por querer contribuir com o projeto **Notícias Brasil & Japão**!

## Adicionando uma notícia

1. Crie um arquivo `.md` na pasta correspondente (`brasil/`, `japao/` ou `brasil-japao/`)
2. Use o formato abaixo:

```markdown
# Título da Notícia

**Data:** 2026-08-21  
**Fonte:** Nome da Fonte  
**Link:** https://exemplo.com/noticia  
**Categoria:** Politica / Economia / Cultura / etc.

## Resumo

Escreva um resumo claro e objetivo da notícia.

## Destaques
- Ponto importante 1
- Ponto importante 2
```

3. Abra um Pull Request explicando a notícia adicionada.

## Regras

- Use apenas fontes confiáveis
- Não copie o texto inteiro da matéria (respeite direitos autorais)
- Prefira resumos em português
- Inclua sempre o link original
